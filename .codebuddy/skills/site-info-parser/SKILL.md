# 站点信息解析

## 用途

给定一个或多个网站链接，产出结构化的站点信息（字段顺序固定）：

- `title`：网站标题（**不超过 6 个字**，超长必须提炼缩短，否则前端渲染溢出）
- `url`：规范化链接（去掉尾部 `/`）
- `icon`：站点图标地址（解析失败时回退到默认图标）
- `description`：描述文本（需润色为 32 字左右的中文）

## 使用方法

运行内置脚本（零依赖，Node 18+）：

```bash
node <skill目录>/scripts/fetch-site-info.mjs <url1> [url2 ...]
```

支持不带协议的输入（自动补 `https://`）。脚本原始输出为 JSON 数组（含 `input`、`error` 等中间字段），仅作解析依据；**最终产出必须是且仅是固定的四个字段**：

```json
{
  "title": "考试酷",
  "url": "https://www.examcoo.com/index/ku",
  "icon": "https://www.examcoo.com/favicon.ico",
  "description": "永久免费的在线考试与电子作业平台，提供海量公共题库、自测练习与智能组卷服务。"
}
```

字段顺序固定为 title → url → icon → description。站点解析失败（脚本返回 error）时，四字段照常产出：title 以域名为依据提炼为不超过 6 字的站点名，url 用域名，icon 用默认图标，description 根据已知信息补写，并如实告知用户该站抓取失败。

## 后处理规则（必须执行）

1. **title 提炼（≤6 字）**：脚本返回的是页面原始标题，通常远超 6 字，必须提炼为 **不超过 6 个字**的简短站点名（如「考试酷在线考试平台」→「考试酷」）；提炼不了时截取核心词。用户已提供标题的站点，直接采用用户提供值，不润色；若用户提供的值本身超过 6 字，提炼缩短并向用户说明。
2. **description 润色**：脚本返回的是页面原始 description，可能为英文、空或不通顺。必须基于标题和原文重写为 **32 字左右（28~36 字）的简体中文描述**，语义准确、语言精炼；原文为空时根据站点名称与用途补写。产出前先报告字数核对。
3. **icon 缺省**：脚本已内置回退逻辑，icon 拿不到时自动使用默认图标 `https://q1.qlogo.cn/g?b=qq&nk=1207588603&s=640`，无需再处理。

## 注意事项

- 产出前**逐条自检**（必须执行，任一不达标先修正再输出）：
  1. 结果中**只有 title、url、icon、description 四个字段**，无多余字段，顺序为 title → url → icon → description；
  2. `url` 无尾部 `/`、无 hash；根域名只保留 `https://host` 形式；
  3. `icon` 为合法 http(s) 地址（数据来源或默认图标）；
  4. `title` 不超过 6 个字：用户提供的站点与用户值语义一致（超长时已提炼并说明），未提供的站点为脚本标题的提炼结果；
  5. `description` 为简体中文且字数在 28~36 之间，输出前报告实际字数。
- 脚本只负责抓取与解析，description 润色由会话内完成，不要让脚本做文案。
- 站点需要登录、反爬拦截或超时（默认 15s）时，脚本会在 JSON 中给出 `error` 字段，如实告知用户该站点解析失败，不要编造数据。
- 多个 URL 一次性传入脚本参数，不要逐个调用。
